# em_graph_memory

Code and paper repository for Entity--Memory graph retrieval on LoCoMo.

## Contents

- code/: active graph construction, retrieval, cache, and frozen evaluator code.
- data/: dataset required to rerun the formal evaluation.
- experiments/: formal runner, settings, evidence, and reproduction notes.
- outputs/: retained formal results and audit artifacts.
- paper/entity_memory_graph_retrieval_arxiv_en_v108.pdf: latest v108 paper PDF.

The paper PDF links to the current main branch of this repository. The legacy
top-level em_graph package was removed because it is not used by the paper's
current three-package implementation.
